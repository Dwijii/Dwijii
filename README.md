## How I work

1. **Start from the business process.** Who's waiting, what's falling through, what a good handoff looks like.
2. **Put rules before models.** Deterministic filters and validation first; the LLM only where judgement is needed.
3. **Make it testable.** Explicit output contracts, evaluation scenarios, logged runs.
4. **Write down the decisions.** Every project has architecture decision records explaining the trade-offs.
